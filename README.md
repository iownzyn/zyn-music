## Start
`pip install -r requirements.txt` then `python -m SayaMusic`.
For Render choose **Background Worker**.

## Required environment variables
`API_ID`, `API_HASH`, `BOT_TOKEN`, `MONGO_DB_URI`, `STRING_SESSION` and `LOGGER_ID`.

Set these privately in your host dashboard. Never commit real tokens, session strings, cookies or database credentials.

Defaults: OWNER_ID=9100108789, OWNER_USERNAME=shadowxtemp, BOT_USERNAME=ZynMusicBot, BOT_NAME=𝐙𝐘𝐍 𝐌𝐔𝐒𝐈𝐂 🎧, LOGGER_ID=-1004420640566, SUPPORT_CHANNEL=https://t.me/zynmusicupdates, SUPPORT_CHAT=https://t.me/zynmusicupdates, UPSTREAM_REPO=https://github.com/iownzyn/zyn-music, UPSTREAM_BRANCH=main.
